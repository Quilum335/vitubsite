# NORMAS — студия 3D VTuber-персонажей

Русскоязычный сайт: главная, три страницы услуг, три статьи и страница источников. Статический HTML с локальными CSS, JS, шрифтами и 3D-моделями. Можно разместить на обычном Nginx-хостинге без Node.js на сервере.

## Vercel

Импортировать этот репозиторий через Vercel → Add New → Project. Файл vercel.json задаёт Framework Other, Build Command npm run build и Output Directory dist. Пошаговый запуск, подключение домена и поисковых консолей описаны в [DEPLOY.md](DEPLOY.md).

## Быстрый просмотр

Из этой папки: `python -m http.server 5173 --directory dist`, затем открыть `http://localhost:5173`.

Если меняется просмотрщик: `npm install`, затем `npm run build`. Исходник: `src/viewer.js`; собранный файл: `dist/assets/viewer.js`.

## Контакты

В `dist/assets/config.js` вписать реальный Telegram вида `https://t.me/username` и почту. Кнопки появятся в футере и брифе. Пока контакты пустые, посетитель может скачать или скопировать бриф; данные никуда не отправляются. Серверная обработка заявок не подключена.

## Модели

Подключены десять GLB из проекта 3d_models_zar: Catgirl, Lilac, Teal, Rang, Demoneesa, Succub, Devil, Coral, Turquoise, Sunshine. Главная модель — Catgirl. Исходные пользовательские файлы не изменены: копии лежат в dist/assets/models. Каталог — src/models.js и dist/assets/models.json. Изображения для предварительного просмотра взяты из локальных рендеров проекта и уменьшены для сайта.

История src/world.js управляет камерой, каркасным материалом без запуска танцевальных клипов. Коллекция загружает только выбранную модель. GLB с морфами поддерживает доступные улыбку и открытие рта; несуществующие эмоции отключены. Полный трекинг для VTubing не заявляется. Coral и Turquoise исходно не имеют цветных текстур.

GLB, открытый посетителем локально, остаётся в браузере. Кнопка «Сохранить кадр» скачивает PNG. Для пересборки просмотрщика: npm run build.

## SEO и запуск на normas.eu.cc

Текущая сборка закрыта от индексации. Доступ к развёрнутому сайту задаётся настройками хостинга; robots.txt не ограничивает просмотр. Подготовлены отдельные HTML-страницы, title/description, внутренняя перелинковка, доступный текст, canonical и sitemap. Спрос и позиции в поиске ещё не измерены.

Перед публичным запуском:

1. Указать контакты и окончательный состав услуг.
2. Выполнить `node prepare-seo.mjs https://normas.eu.cc public`. Это переключит robots/noindex, canonical и sitemap на домен.
3. Направить A-запись `@` на публичный IP сервера. Для `www` добавить A-запись и настроить постоянное перенаправление на основной домен.
4. Разместить содержимое `dist/` в каталоге сайта. Настроить веб-сервер на `normas.eu.cc`, HTTPS и выдачу `index.html` внутри каталогов. Несуществующие страницы должны возвращать 404.
5. Добавить сайт в Яндекс Вебмастер и Google Search Console, отправить `/sitemap.xml`, подключить аналитику по своему решению.

Команда `node prepare-seo.mjs https://your-preview-origin draft` возвращает режим закрытого предпросмотра.

## Дизайн

История с пятью главами: замысел, форма, движение, выход. Собственная иллюстрация чернильного мира и портала, движения камеры, переход из бумаги в ночную пространственную среду. От Santioni Spirits взяты принципы рисованной атмосферы и повествования при прокрутке, от Cyera Secure the Unknown — объёмная среда и исследование коллекции. Чужие изображения не копировались. Иллюстрация сгенерирована встроенным imagegen, шрифты Manrope и Cormorant Garamond — SIL OFL.

## Проверки

Отчёт проверки и скриншоты находятся рядом с исходниками в outputs. Перед переносом на собственный сервер проверить HTTPS, индексацию, контакты и DNS уже на реальном домене.
